Grid lines allow us to define positions on a grid, allowing us to place elements in whatever section of the grid, not
necessarily in order.

If a grid has 8 columns, it has 9 column lines.
If a grid has 4 rows, it has 5 row lines.

General rule:
number of lines = number of tracks + 1

So:
- columns + 1 = column lines
- rows + 1 = row lines

Example with 8 columns:

  1    2     3     4     5     6     7     8     9
  |    |     |     |     |     |     |     |     |
  [----][----][----][----][----][----][----][----]
   col1  col2  col3  col4  col5  col6  col7  col8

The numbered vertical lines are the column lines.

Example with 4 rows:

  line 1  --------------------------------
          row 1
  line 2  --------------------------------
          row 2
  line 3  --------------------------------
          row 3
  line 4  --------------------------------
          row 4
  line 5  --------------------------------

The numbered horizontal lines are the row lines.
